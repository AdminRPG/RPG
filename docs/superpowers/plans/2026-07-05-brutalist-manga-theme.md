# Brutalist Manga Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Inline execution by session owner.

**Goal:** Rewrite the I-Forge RPG MyBB theme CSS and index template to a solid brutalist manga/panel style with green-gold on parchment.

**Architecture:** Single CSS file (`iforge.css`) overrides all MyBB defaults with solid colors, hard shadows, and thick borders. Single custom `index` template + `headerinclude` template in templateset sid=10. Export/import via XML maintained in `docs/themes/iforge-child-theme.xml`.

**Tech Stack:** MyBB 1.8, raw CSS, MyBB template system.

## Global Constraints
- No `rgba()` or `opacity < 1` on panel/container backgrounds.
- No `backdrop-filter`, `blur`, or glassmorphism.
- All panels: `3px solid #1e3d1a` border + `box-shadow: 4px 4px 0 #1e3d1a`.
- Maximum `border-radius: 4px`.
- Typography: brush/cursive for titles, serif for body, sans-serif for nav.

### Task 1: Rewrite CSS (iforge.css)

**Files:**
- Modify: `docs/themes/iforge-child-theme.xml` (stylesheet CDATA)
- Modify: DB `mybb_themestylesheets` (sid=29, tid=10)

**Interfaces:**
- Consumes: None (pure CSS)
- Produces: Visual rules applied to all `.iforge-*` classes and MyBB overrides.

- [ ] **Step 1: Write the new CSS**
  Replace the entire CDATA of `iforge.css` in the XML and DB with the new brutalist CSS.

- [ ] **Step 2: Update in DB**
  Run PHP script to update `mybb_themestylesheets` row sid=29 with the new CSS content.

- [ ] **Step 3: Verify CSS endpoint**
  Fetch `http://localhost/iforge/css.php?stylesheet%5B%5D=29` and confirm it returns the new CSS.
