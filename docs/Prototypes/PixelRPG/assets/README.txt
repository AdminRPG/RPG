RETRATOS / SPRITES — PixelRPG
================================

Suelta aquí los PNG de los personajes. Se cargan como sprite/retrato
dentro de los marcos con borde de ventana JRPG. Si el archivo no existe,
aparece automáticamente el "fallback" con las iniciales.

Archivos esperados (mismos nombres que en NeoBrutalism para reutilizar):
  vania.png      -> Vania Korr   (ficha.html, tema.html, HUD de todas las páginas)
  fundidor.png   -> Fundidor     (tema.html)
  ren.png        -> Ren Duro     (tema.html)

Recomendado:
  - PNG con fondo transparente, encuadre de retrato (cabeza/torso).
  - Relación ~4:5 o cuadrada. Se escala con image-rendering: pixelated,
    así que un sprite de pixel-art se verá nítido y "de videojuego".
  - Si usas arte de alta resolución, también funciona (object-fit: cover).
