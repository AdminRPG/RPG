RETRATOS DE PERSONAJE (PNG)
===========================

Suelta aquí los PNG de los personajes. La ficha y la vista de tema los
cargan por nombre y, si no existen, caen con elegancia a las iniciales.

Rutas usadas por los prototipos:
  - ficha.html  -> assets/vania.png   (retrato grande, marco forjado 4:5)
  - tema.html   -> assets/vania.png, assets/ren.png, assets/fundidor.png ...

Recomendaciones:
  - PNG con fondo transparente (recorte del personaje) para que "encaje"
    dentro del resplandor de brasa del marco.
  - Proporción vertical ~4:5 para la ficha; cuadrado para los avatares de tema.
  - El sistema no depende de la imagen: si falta, se muestran las iniciales.
